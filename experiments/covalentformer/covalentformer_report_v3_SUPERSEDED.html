CovalentFormer: a language model for covalent hit-to-lead

Qwen2.5-7B + LoRA (r=16, α=32) · three-rung curriculum, 503,895 rows · held-out evaluation · internal report, 28 Sep 2026

Summary

Given a protein pocket and a covalent hit, the model proposes a covalent analogue. Trained on all

Given a protein pocket and a covalent hit, the model proposes a covalent analogue. Evaluated on the prompt format it was actually trained on, it recovers the exact held-out analogue in 21.8% of cases within 30 samples (50/229), against 0.0% for an arm trained on the same corpus minus the design task, and 3.1% for an external Mol2Mol prior at the same k.

10 samples (36/229); an arm trained on the same corpus minus the design task reaches 0.4% and returns its input unchanged 43% of the time.

The finding that governs everything else. Splitting every evaluation by whether the correct answer already exists somewhere in the training corpus separates recall from generalisation. On external covalent programs, where the answer is a training molecule, joint scores 7.46% against the control's 0.00% (p<0.0001). Where the answer is not in training, joint scores 1.89% and the control scores 1.89% — identical, p=1.0000. The three-rung curriculum produced a much better retriever; it produced no measurable gain on novel chemistry.

A second defect bounds the rung-3 numbers: they were measured under a prompt mismatch (§7.1) — the model was evaluated with an instruction it was never trained on. A matched re-run is in progress.

The pocket representation. A 56-dimensional descriptor rendered as prose: 48 dims = 4 lateral quadrants × 3 shells (<4, 4–7, 7–10 Å) × 4 residue classes; 4 = nearest-wall distance; 4 = fraction of contacts on the attack side. Residue classes only, never names, and atoms within 2.6 Å of the electrophile are excluded so the reacting side chain cannot leak.

Its known weakness. The frame is per-complex, so quadrant identity (+x-y) carries no meaning across complexes — only the scalars (counts, wall distance, attack-side fraction) are transferable. A chemist can read it but cannot map a quadrant onto a real pocket feature: there is no gatekeeper, back pocket or solvent front. Two fixes are available and cheap: sort quadrants canonically (roomiest first) to make the encoding permutation-invariant, and name subpocket features per target family so the text means the same thing across complexes.

What the three differ in, concretely. Only CovalentFormer receives the pocket, and only it is asked to name the reacting residue. Only CovRXN returns a potency estimate. Mol2Mol receives the least and knows nothing about covalency — which is why it is the right control for "how much of the score needs covalent training at all".

6Recall or generalisation?

Exact-match cannot distinguish recalling a training molecule from designing a new one. So every molecule appearing anywhere in the corpus as an input or a target was collected — 224,168 unique, counterion-stripped canonical SMILES — and every evaluation was split on whether its answer is in that set. This is the same model and the same generations as Tables 5 and 6; only the partition is new.

What this means, and what it does not. Pooled across both evaluations the model recovers 3 of 179 genuinely novel answers (1.68%, 95% CI 0.47–4.40%), so the headline 15.72% and 4.72% are recall measurements. The curriculum demonstrably works on seen chemistry — it beats both the rung-1 control (p<0.0001) and an external generic analogue generator (p=0.0065) there. On unseen chemistry it is indistinguishable from the control (p=1.0) and shows no advantage over Mol2Mol, a prior with no covalent training at all.

This does not prove the model cannot generalise — 179 novel cases give a wide interval and none of the unseen comparisons reach significance. It does mean the covalent-specific curriculum has not yet been shown to buy anything a generic generator does not already provide on new targets, and that a larger disjoint test set is the experiment that settles it.

7Provenance and corrections

Two defects found while preparing this report. Both are stated because both change how the numbers should be read.

7.1Train/eval prompt mismatch

The joint model trained on R3_COV, whose task line ends “…State which protein residue the warhead reacts with, then give the analogue.” It was evaluated with R3_COVPOCK prompts, ending “…then which quadrant has most room and how the analogue changes, then give the analogue.” The model was asked for quadrant reasoning it was never trained to produce, and invented a Quadrant …: format that occurs in zero training rows — confabulation driven by the mismatch. Verified: the training mixture contains 7,878 rung-3 rows with Pocket: 0 and Change: 0. Table 3 is therefore a lower bound for the matched condition; a matched re-run is in progress.

7.2Pairs that were not pairs

The pair builders compared hit and analogue as raw SMILES strings. Two strings can spell one molecule:

hit as written“analogue” as writtenactually
OB(O)c(c1)sc(c12)cccc2OB(O)c1cc2ccccc2s1identical — ring-closure numbering
…NC(=O)/C=C/CN(C)C…NC(=O)\C=C\CN(C)Cidentical — both trans
…[C@H]1C.Cl…[C@H]1Cidentical — salt vs free base

The op classifier compared heavy-atom counts, so a zero difference passed as NONE without comparing molecules. Affected 9/2,626 rung-3 training rows, 1/230 test rows and 11/1,200 covPROG pairs. A canonical, counterion-stripped gate now guards every builder; all figures here use the cleaned sets (rung 3 = 2,616; test = 229).

9Limits

  • Exact-match measures recall, not generalisation. 91.3% of held-out answers are training molecules; on the 20 that are not, exact@10 is 0.00% (§6). The disjoint set has since been enlarged from 179 pooled cases to 538 by harvesting the covPROG rows that were never scored (only 60 of ~200 per program had been used); FGFR4 is 190/190 unseen. That should narrow the interval enough to separate "ties the control" from "modestly better".
  • No trained reasoning trace. The model emits a residue and a molecule. Any pocket commentary it produces is confabulated (§7.1).
  • The pocket may be inert. Four experiments found pocket-in-prompt carries no signal, and the ablation designed to test pocket-in-output (R3_SMILES / R3_COVPOCK as trained arms) has not been run. No claim is made that the pocket contributes.
  • One chemotype dominates, and the shipped labels were ambiguous. Re-measured structurally with a most-specific-first SMARTS taxonomy: acrylamide is 77.0% of rung 2. 96.0% of rows labelled michael_acceptor also match the acrylamide pattern, and 79% of molecules match more than one warhead class, so the flat declared labels could not be correct; 4.0% match no known warhead class at all.
  • exact@1 near floor (4.80% held-out, 0.83% on programs): the output is a pool, and the ranker does not exist yet.
  • Every potency model so far was trained on survivors only. The affinity corpus was mined with a ≥3× improvement filter, so its minimum ΔpIC50 is +0.48 across all 143,075 pairs and no model has ever seen an edit that failed. A ranker trained that way cannot recognise a bad candidate — only order good ones. Re-mining the same source without the filter yields 739,708 pairs: 28.6% improving, 41.3% neutral, 30.1% degrading, Δ spanning −3.00 to +3.00. Both streams' potency heads need retraining on it before any ranking claim is made.

The frame, fixed and then actually tested. ±x was chosen by picking the electrophile's neighbour with the largest connected component, tie-broken on atom name. That tie fired in 13.6% of the original complexes and 19.8% of the newly parsed ones — and it cannot discriminate at all when the electrophile sits in a ring, since deleting it disconnects nothing. Replaced with the direction to the Murcko-core centroid: a centroid is continuous, so exact ties have measure zero. Result: 85.7% core centroid, 14.3% ligand centroid, 0% discrete fallback, and coverage rose from 1,693 to 1,716 complexes because the centroid rule succeeds where the neighbour rule returned nothing. Verified end to end by rotating and translating 60 raw PDB files and re-running the whole extractor: 60/60 identical, median deviation 0.003 Å, max 0.017 Å — inside PDB write precision. The previous QA re-encoded coordinates that were already canonical, so it would have passed with the frame code deleted.

v4b drops the frame entirely. Every number it prints is an interatomic distance, so rotation and translation invariance holds by construction and the anchor question dissolves rather than being answered. That matters beyond elegance: an anchor defined as “the atom the question concerns” is circular at inference, because at test time the edit is the output. The literature agrees — published pocket-conditioned models use inertial/PCA frames, per-atom local frames, or full SE(3) invariance; none frames on a reaction centre. Our covalent frame is defensible (origin and +z are the same chemical event in all 6,124 complexes) but it is our construction, not a literature method, and it does not extend to non-covalent complexes. Dropping the covalent requirement raises the available corpus from 6,147 complexes to a measured 181,929 ligand records and 3.63M interactions on the 76,840-structure mirror — the no_covalent_link 92.8% rejection rate was the corpus, not a failure.

The replacement rung-3 fold. The old folds were cut from the same cdl.jsonl that v4's rung-3 corpus is built from, so no filter can make them disjoint — decontaminating against them leaves 1,083 of 5,518 rows. Instead, (hit, analogue) pairs are treated as edges in a molecule graph and whole connected components are assigned to one side: train 4,501 / test 1,017 rows, molecule intersection 0, pair intersection 0, test spanning CYS 783 / SER 227 and all six transformation ops. The split depends only on the molecule graph, so it is identical under both encodings — v4 and v4b will be scored on the same 1,017 pairs with the same targets, differing only in the pocket block. That makes the frame a one-axis test.

Where potency lives. Hanging ΔpIC50 on the rung-3 rows is impossible and the count says so: 1 of 5,518 rung-3 pairs has a measured ΔpIC50, against 2,031 of 79,241 rung-2 pairs. Rung 3 needs both members to have a solved covalent co-crystal; potency lives in ChEMBL/covindb for compounds that were mostly never crystallised. So affinity rides as its own row type and the head's masked loss gives unlabelled rows weight zero — no fabricated targets. The Predicted dpIC50: line is now stripped in the data, so no future trainer can reintroduce the v3 leak by forgetting to.

What contacts is actually worth. Rebuilt as interaction-type prediction off the real fingerprint, it survives a trivial-baseline attack where the old version did not. But the honest headroom is smaller than first reported: against a distance-aware lookup (residue class × 0.5 Å bucket) the baseline reaches 73.6% on a 36.3% floor — 26.4 points, not the 54 I first quoted from a baseline that could not read distance. Distance largely determines interaction type. It is a real task but a marginal one, which is why it is capped rather than run at full size.
