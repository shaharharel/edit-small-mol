# Dashboard Column Dictionary

Reference for every column shown in the Mol 1 generation report dashboard
(`experiments/server/report.html`, served by `experiments/server/backend.py`
on port 5001). Grouped in the same order as the detail-modal sections.

Each entry gives:

- **What:** one-line definition
- **How:** concrete computation — script / function / formula
- **Intuition:** typical range and what to do with the value as a medchemist

---

## IDENTITY

### `smiles`

- **What:** Canonical SMILES of the candidate molecule.
- **How:** Stored in `all_methods_bulk_scored_v4.csv`; produced by each generation method (Tier 1/1.5/2/3) and standardised by RDKit `Chem.MolToSmiles(MolFromSmiles(...))`. The backend filters disconnected (multi-fragment) SMILES via `df["smiles"].str.contains(".", regex=False)` in `backend.py:91`.
- **Intuition:** Free-form text — sanity-check kekulisation, presence of the warhead (`C=CC(=O)N...`), and absence of `.` fragment separators. Click the row for the 2D depiction.

### `method`

- **What:** Generation method bucket (Medchem Rules / Amine Replacements / Tier 3 sub-methods).
- **How:** Set per generation script; unified in `backend.py:62-69` — Tier 1 + 1.5 collapse to `"Medchem Rules"`, Tier 2 + Tier 2 SCALED collapse to `"Amine Replacements"`. Tier 4 + Methods A/B are dropped (line 72-79).
- **Intuition:** Use to compare productivity of generation strategies; filter to one method via the sub-nav pill or `/api/data?method=`.

### `row_id`

- **What:** Stable 0-based index used as primary key across all merged sources.
- **How:** Assigned in `backend.py:56` and again at line 93 after method/warhead/disconnected filters: `DF["row_id"] = DF.index`. Mirrored in every downstream CSV (efficiency_metrics, pubtc_scores, rdkit_strain_*, propka_csv, vina_csv, warhead_reactivity) so cross-merge is by `row_id`.
- **Intuition:** Integer, range 0 to ~520K. Persists across re-loads as long as the bulk CSV doesn't change. Used by `/api/svg/<row_id>` and `/api/pose/<row_id>`.

### `yaml_name`

- **What:** Filesystem-safe identifier for the candidate's Boltz cofold YAML/CIF/PDB files.
- **How:** Generated by `experiments/boltz_inputs_top1000.py` (line 158) as a deterministic short name (typically `<method-prefix>_<index>`); stored in `data/boltz_poses/top1000_manifest__zap70_cys346.json` and merged in `backend.py:115`. Used by `_resolve_pose()` to locate `<yaml_name>_model_0.cif`.
- **Intuition:** Only populated for the 997 cofolded candidates; NaN for the rest. Use to find the on-disk pose at `data/boltz_poses/boltz_results_top1000__zap70_cys346/predictions/<yaml_name>/`.

### `compound_id`

- **What:** External / stable compound identifier when assigned (currently sparse).
- **How:** Populated by upstream scoring pipelines (`overnight_method_by_method_report.py` etc.) when a method emits stable IDs; otherwise falls back to `row_id` in the dashboard. Not always present.
- **Intuition:** Use to cross-reference compounds across reports / external registries. When NaN, treat `row_id` as the de facto ID.

## PREDICTED POTENCY

### `pIC50_method`

- **What:** Method-uniform single-seed FiLMDelta anchor-mean pIC50 prediction.
- **How:** For each method's scored CSV, the per-molecule FiLMDelta score is reconciled into a unified `pIC50_method` column in `experiments/compute_bulk_metrics_all_methods.py:197-206`. Score = mean over 280 ZAP70 training anchors of `pIC50_anchor + FiLMDelta(anchor, candidate)` for one seed.
- **Intuition:** Primary scoring column. Range typically 4-9 (log-molar IC50). ≥ 7 = "potent" chip; ≥ 8 = "ultra potent". Compare across methods on equal footing.

### `pIC50_mean`

- **What:** 3-seed FiLMDelta ensemble mean pIC50 — the high-confidence prediction.
- **How:** `experiments/compute_pairwise_for_topK.py:103,213` — for the top-K=1000 candidates per method, computes anchor-mean pIC50 for each of 3 FiLMDelta seeds (`reinvent4_film_ensemble/film_seed{0,1,2}.pt`) over 280 anchors, then averages the 3 seed-means. Only filled for top-K per method; NaN elsewhere.
- **Intuition:** More reliable than `pIC50_method` but available for fewer rows. When present, prefer it. Reads like the single-seed pIC50 but with ensemble denoising.

### `pIC50_std`

- **What:** Standard deviation across the 3 seed-anchor-means — ensemble disagreement.
- **How:** `compute_pairwise_for_topK.py:189` — `seed_means.std(axis=0)` over the 3 FiLMDelta seeds.
- **Intuition:** Typical range 0-0.5. < 0.15 = tight ensemble agreement (trust the mean); > 0.4 = model disagreement (treat as low-confidence). Use as a confidence band on `pIC50_mean`.

### `pIC50_film`

- **What:** Alias of `pIC50_method` — exposed under the older name for backward-compat with chip presets and frontend code.
- **How:** Created in `backend.py:97-99`: when only one of `pIC50_method` / `pIC50_film` is present, the missing one is copied. Identical values.
- **Intuition:** Same as `pIC50_method`. Used by chip presets (`potent`, `ultra_potent`, `in_distribution`) and the leaderboard ranking. Pick one and ignore the other.

### `delta_vs_mol1`

- **What:** Candidate's `pIC50_mean` minus Mol 1's baseline pIC50.
- **How:** `compute_pairwise_for_topK.py:193,218`: `mean - mol1_baseline` where `mol1_baseline ≈ 6.77` is the same 3-seed × 280-anchor mean computed for Mol 1.
- **Intuition:** Positive = predicted more potent than the seed. Δ ≥ +1 is the "10x better" zone; ≥ +0.5 is encouraging. Reports relative improvement on a log scale.

### `direct_delta_from_mol1`

- **What:** 3-seed mean of FiLMDelta(anchor=Mol 1, target=candidate) — direct single-anchor prediction.
- **How:** `compute_pairwise_for_topK.py:181,192`: for each ensemble seed, run the FiLMDelta MLP with Mol 1 as the anchor and candidate as the target; average the three deltas.
- **Intuition:** Noisier than `delta_vs_mol1` (single anchor vs 280-anchor mean) but more interpretable: it's literally "what Δ pIC50 does the model predict for this edit from Mol 1?". Use as a cross-check; if it disagrees strongly with `delta_vs_mol1`, the candidate is out-of-distribution for Mol 1.

### `anchor_wins`

- **What:** Number of the 280 ZAP70 training anchors where FiLMDelta predicts the candidate beats the anchor.
- **How:** `compute_pairwise_for_topK.py:190,216`: `(deltas > 0).sum(axis=2).mean(axis=0)` — count of positive deltas per seed, then averaged across 3 seeds. Range 0-280.
- **Intuition:** A wide-coverage potency signal that's robust to anchor cherry-picking. > 200 = predicted to outperform most of the training set; < 50 = predicted worse than most anchors. Less affected by a single noisy anchor than `pIC50_mean`.

### `anchor_wins_ge7`

- **What:** Same as `anchor_wins` but restricted to high-potency anchors (those with measured pIC50 ≥ 7.0; ~55 of the 280).
- **How:** `compute_pairwise_for_topK.py:191`: `((deltas > 0) & high_potency_mask).sum(axis=2).mean(axis=0)`.
- **Intuition:** The strict bar — "does the candidate beat actually potent compounds?". Range 0-~55. > 30 = strong signal; this is the metric that survives most for low-Tc OOD candidates.

## DRUG-LIKENESS

### `MW`

- **What:** Molecular weight in Daltons.
- **How:** RDKit `Descriptors.MolWt(mol)` — sum of atomic masses including implicit Hs.
- **Intuition:** Lipinski < 500; lead-like < 350. Our library spans up to ~700 (kinase inhibitors run heavy). High MW (> 600) impairs oral bioavailability and increases off-target risk.

### `LogP`

- **What:** Crippen octanol/water partition coefficient — lipophilicity.
- **How:** RDKit `Crippen.MolLogP(mol)` — atom-contribution Wildman-Crippen.
- **Intuition:** Lipinski < 5. Sweet spot 1-3. > 5 = greasy (poor solubility, off-target, hERG). < 0 = too polar (membrane permeability concern).

### `TPSA`

- **What:** Topological Polar Surface Area in Å², from polar fragment counts.
- **How:** RDKit `Descriptors.TPSA(mol)` — Ertl 2000 fragment-based estimate.
- **Intuition:** < 140 Å² for oral; < 90 Å² for CNS. > 120 Å² hurts permeability. Use with LogP — high LogP + low TPSA = membrane-friendly but precipitation-prone.

### `HBA`

- **What:** Number of hydrogen-bond acceptors.
- **How:** RDKit `Lipinski.NumHAcceptors(mol)` — count of N and O atoms via the Lipinski definition (no aromatic-N triple counting).
- **Intuition:** Lipinski ≤ 10. Median in our library ≈ 6. > 12 = too many acceptors; flexibility and solubility suffer.

### `HBD`

- **What:** Number of hydrogen-bond donors.
- **How:** RDKit `Lipinski.NumHDonors(mol)` — count of NH/OH including primary amines.
- **Intuition:** Lipinski ≤ 5. Acceptable range 0-3 for kinases. > 5 hurts permeability — strong negative for CNS programs.

### `RotBonds`

- **What:** Number of rotatable single bonds (flexible torsions).
- **How:** RDKit `Lipinski.NumRotatableBonds(mol)` — count of single non-ring non-amide bonds between two heavy atoms with ≥ 1 heavy neighbor each.
- **Intuition:** Veber et al. 2002: ≤ 10 for oral. ≤ 7 is preferred for kinase leads. > 10 indicates a floppy molecule with high entropy penalty on binding.

### `QED`

- **What:** Quantitative Estimate of Drug-likeness (Bickerton et al. 2012) — composite [0,1] score.
- **How:** RDKit `QED.qed(mol)` — weighted product of 8 desirability functions (MW, LogP, HBA, HBD, TPSA, RotBonds, aromatic rings, alerts).
- **Intuition:** Range 0-1. > 0.5 = drug-like; > 0.7 = lead-like; < 0.3 = problematic. Most marketed drugs sit at 0.4-0.8. Use as a coarse first-pass filter, not a hard cutoff.

### `HeavyAtoms`

- **What:** Number of non-hydrogen atoms.
- **How:** RDKit `mol.GetNumHeavyAtoms()`.
- **Intuition:** Fragment-sized ~10-15; lead-like 20-30; clinical kinase inhibitors 35-50. Denominator of `LE`. Use to spot oversized molecules even when MW looks fine.

### `Rings`

- **What:** Number of rings (smallest set of smallest rings, SSSR).
- **How:** RDKit `rdMolDescriptors.CalcNumRings(mol)`.
- **Intuition:** Typical drug 2-5 rings. > 6 = scaffold complexity rising fast; check `fsp3` and `SAScore` to ensure synthesizability didn't suffer.

### `fsp3`

- **What:** Fraction of sp3 carbons — saturation / 3D-ness proxy.
- **How:** RDKit `Lipinski.FractionCSP3(mol)` in `experiments/compute_efficiency_metrics.py:50` — count of sp3 C / total C.
- **Intuition:** Lovering 2009: higher fsp3 → better clinical success. Our library median ≈ 0.30. > 0.40 = 3D-rich (good); < 0.20 = flat aromatic (potential clinical attrition risk).

### `Lipinski_violations`

- **What:** Count of Rule-of-Five violations (Lipinski 1997).
- **How:** `compute_efficiency_metrics.py:125-130` — `(MW>500) + (LogP>5) + (HBA>10) + (HBD>5)`. Range 0-4.
- **Intuition:** 0 = ideal oral. 1 = acceptable (most kinases violate one). ≥ 2 = oral risk. Veber et al. add RotBonds and TPSA as further filters.

### `SAScore`

- **What:** Ertl-Schuffenhauer Synthetic Accessibility Score.
- **How:** RDKit Contrib `sascorer.calculateScore(mol)` invoked in `experiments/compute_bulk_metrics_498k.py:122` — combines a fragment-frequency prior (1M PubChem) with complexity penalties (rings, stereo, macrocycles).
- **Intuition:** Range 1-10. 1-3 = trivial; 3-5 = standard medchem; 5-7 = challenging custom synthesis; > 7 = essentially impossible without dedicated route work. Hard filter at < 4 for `synthesizable` chip.

### `PAINS_alerts`

- **What:** Count of Pan-Assay Interference substructure matches (Baell & Holloway 2010).
- **How:** RDKit `FilterCatalog.FilterCatalog(PAINS)` in `compute_bulk_metrics_498k.py:126` — counts substructure matches from the curated PAINS A/B/C catalogs.
- **Intuition:** 0 = clean. ≥ 1 = likely false-positive in screens (quinones, redox-cyclers, Michael acceptors that aren't our designed warhead). Note: the acrylamide warhead itself does NOT trigger PAINS, so a positive PAINS hit is a real concern. Hard filter via `pains_clean` chip.

### `warhead_intact`

- **What:** Boolean — does the candidate retain the acrylamide warhead (`[CH2]=[CH]-C(=O)-[N;!H2]`)?
- **How:** `compute_bulk_metrics_498k.py:128`: `mol.HasSubstructMatch(Chem.MolFromSmarts("[CH2]=[CH]-C(=O)-[N;!H2]"))`. The `!H2` excludes primary amines but allows secondary/tertiary amide N (Mol 1 has tertiary).
- **Intuition:** Must be `True` for any covalent design — `backend.py:84` hard-filters at load time. The chip `warhead_intact` enforces this. If `False`, the warhead was modified by the generation method and the molecule is no longer a Cys346 trap.

## LIGAND EFFICIENCY

### `LLE`

- **What:** Lipophilic Ligand Efficiency — potency that's not "bought" with lipophilicity.
- **How:** `compute_efficiency_metrics.py:112`: `pIC50_method − LogP`. Hopkins & Leeson 2014.
- **Intuition:** Median in our dataset ≈ 1.8. Leeson NRDD 2007: ≥ 5 "good", ≥ 7 "excellent" kinase lead. < 3 means the predicted potency is being bought by greasiness — ADMET trouble. Use as a hard filter (LLE ≥ 4) before ranking.

### `LE`

- **What:** Ligand Efficiency — potency per heavy atom (kcal/mol/atom).
- **How:** `compute_efficiency_metrics.py:113`: `(1.4 × pIC50_method) / HeavyAtoms`. Hopkins, Groom, Alex 2004; the 1.4 factor converts pIC50 to kcal/mol at 298 K.
- **Intuition:** Fragment LE ≥ 0.30 (Astex rule); lead-like LE ≥ 0.25; clinical drugs ~0.20-0.30. < 0.20 = the molecule is paying its size in atoms but not getting potency back.

### `BEI`

- **What:** Binding Efficiency Index — potency per kDa.
- **How:** `compute_efficiency_metrics.py:114`: `(pIC50_method × 1000) / MW`. Abad-Zapatero & Metz 2005.
- **Intuition:** Range typically 10-35. > 27 = efficient (Abad-Zapatero threshold for "good"). Complements LE — penalises heavy atoms more aggressively per Dalton.

### `SEI`

- **What:** Surface-Efficiency Index — potency per polar surface area.
- **How:** `compute_efficiency_metrics.py:115`: `(pIC50_method × 100) / TPSA`. Abad-Zapatero & Metz 2005.
- **Intuition:** High SEI = potent and non-polar (cheap polar surface); low SEI = lots of polar surface for the potency you get. Combine with BEI for a 2D efficiency plot (the BEI-SEI radar from the Abad-Zapatero paper).

### `SILE`

- **What:** Size-Independent Ligand Efficiency — Reynolds 2008 normalisation.
- **How:** `compute_efficiency_metrics.py:116`: `pIC50_method − 0.6·LogP − 0.0035·MW + 4.0`. Empirical correction that removes the size and lipophilicity baselines.
- **Intuition:** Range 0-7 typically. > 4 = efficient. Negative = the candidate is performing worse than the average ligand of its size and LogP. Best metric for fair cross-size comparison.

## SIMILARITY — INTERNAL

### `Tc_to_Mol1`

- **What:** Tanimoto similarity (Morgan FP r=2, 2048 bits) to the seed Mol 1.
- **How:** `compute_bulk_metrics_498k.py:114`: `DataStructs.TanimotoSimilarity(MOL1_FP, fp)` where both FPs are `AllChem.GetMorganFingerprintAsBitVect(mol, 2, nBits=2048)`.
- **Intuition:** Range 0-1. 1.0 = identical. ≥ 0.4 = recognisable analog. ≥ 0.7 = near-identical scaffold (low novelty). < 0.2 = genuinely novel scaffold. Mol 1 itself = 1.0.

### `max_Tc_train`

- **What:** Maximum Tanimoto to the closest of the 280 ZAP70 training molecules.
- **How:** `compute_bulk_metrics_498k.py:117`: `BulkTanimotoSimilarity(fp, train_fps).max()` over the 280-mol training set loaded from `experiments/run_zap70_v3.load_zap70_molecules()`.
- **Intuition:** ≥ 0.5 = in-distribution (model should be reliable). 0.3-0.5 = mild extrapolation. < 0.3 = OOD regime where FiLMDelta MAE ≈ 0.86 (from `case_study_v6_results.md`). The `in_distribution` chip filters at ≥ 0.3.

### `mean_top10_Tc_train`

- **What:** Mean Tanimoto to the 10 nearest training molecules — smoother in-distribution signal.
- **How:** `compute_bulk_metrics_498k.py:118-119`: `np.partition(sims, -10)[-10:].mean()`.
- **Intuition:** Less brittle than `max_Tc_train` to single-hit outliers in training. > 0.3 = solid in-distribution; < 0.2 = isolated chemotype. Use as a confidence dial on FiLMDelta predictions.

## SIMILARITY — PUBLISHED LEADS v2

### `max_pubTc`

- **What:** Maximum Tanimoto over a 30-lead curated panel of published kinase covalent inhibitors (v2 panel).
- **How:** `experiments/compute_pubtc_panel.py:132` with `--panel v2`: Morgan FP r=2/2048 Tanimoto to each panel SMILES from `pubtc_panel_v2.py` (30 leads spanning BTK, EGFR, KRAS, JAK3, SYK, etc.; chemotype-balanced caps: ≤5 BTK, ≤4 EGFR, ≤3 KRAS).
- **Intuition:** Range 0-1. ≥ 0.5 = recognisable analog of a published lead — promising AND IP-risky. < 0.2 = scaffold is genuinely new vs publicly disclosed covalent kinase inhibitors.

### `median_pubTc`

- **What:** Median Tanimoto across the 30 panel members.
- **How:** `compute_pubtc_panel.py:133`: `float(np.median(tcs))`.
- **Intuition:** Background-noise level. 0.10-0.15 typical for a random kinase ligand. Catches "broadly kinase-like" character regardless of which specific lead it resembles.

### `mean_pubTc`

- **What:** Mean Tanimoto across the 30 panel members.
- **How:** `compute_pubtc_panel.py:134`: `float(tcs.mean())`.
- **Intuition:** Similar story to median but more sensitive to outlier high-Tc hits. Same baseline ~0.10-0.15.

### `top3_mean_pubTc`

- **What:** Mean of the three highest Tanimotos — robust analog signal.
- **How:** `compute_pubtc_panel.py:129`: `tcs[order[:3]].mean()`.
- **Intuition:** More stable than `max_pubTc` (single-FP collisions can spike). > 0.4 = strong family resemblance to published leads.

### `closest_lead`

- **What:** Name of the panel member with the highest Tanimoto — the most similar published lead.
- **How:** `compute_pubtc_panel.py:136`: `_PANEL_NAMES[int(order[0])]`.
- **Intuition:** Read as "this candidate is closest to X". Useful for IP-prior-art triage and to spot if the dashboard is rediscovering known chemotypes (e.g. ibrutinib analogs).

## SIMILARITY — 3D SHAPE / ESP

### `shape_Tc_seed`

- **What:** 3D shape Tanimoto vs Mol 1 — Gaussian-volume similarity after alignment.
- **How:** `src/utils/mol1_scoring.py:209-236`: embed candidate as a 4-conformer ETKDG+MMFF ensemble, align each candidate conf to each Mol 1 seed conf via RDKit `rdMolAlign.GetO3A`, compute `1 - rdShapeHelpers.ShapeTanimotoDist`, keep the best. Driven by `experiments/compute_3d_for_all_aichem.py`.
- **Intuition:** Range 0-1. > 0.7 = strong 3D footprint preservation (good for surface-isosteres). < 0.4 = candidate occupies a substantially different 3D volume than Mol 1. *Computed only for top-100 per method* — NaN elsewhere.

### `esp_sim_seed`

- **What:** Electrostatic + shape similarity to Mol 1 — ESPSim Tanimoto with Gasteiger charges.
- **How:** `src/utils/mol1_scoring.py:239-260`: same 4-conformer alignment as `shape_Tc_seed`, then `espsim.GetEspSim(cand, seed)` — Gaussian-volume combined with Gasteiger partial charges.
- **Intuition:** Range -1 to +1. > 0.6 = matching polar regions (same H-bond pattern); ~0 = shape matches but electrostatics differ; < 0 = anti-correlated polarity. Distinguishes shape-isosteres that swap H-bond donors/acceptors. *Top-100 per method only*.

### `warhead_dev_deg`

- **What:** Minimum angle (degrees) between Mol 1's C=C–C(=O)–N warhead vector and the candidate's after 3D alignment.
- **How:** `src/utils/mol1_scoring.py:263-309`: align candidate to Mol 1 via O3A, compute angle between `(Cβ → N)` vectors of the SMARTS-matched warheads across conformer pairs, return the minimum.
- **Intuition:** 0° = warhead points the same way as Mol 1 (good — covalent reach to Cys346 preserved). > 90° = pointing away. < 30° preferred for retaining the covalent geometry. NaN if warhead is missing or alignment fails. *Top-100 per method only*.

## COFOLD GEOMETRY

### `d_SG`

- **What:** Distance (Å) from ligand warhead Cβ to Cys346 Sγ in the Boltz cofold pose.
- **How:** Computed during cofold post-processing and written into `data/boltz_poses/top1000_manifest__zap70_cys346.json` (see `anchordiff/build_cys346_manifest_json.py` for the manifest builder); merged in `backend.py:166`.
- **Intuition:** Michael-addition transition state Cβ–Sγ ≈ 1.83 Å (full bond), ~3.5 Å for vdW contact. ≤ 3.0 Å = "already in attack geometry"; ≤ 4.5 Å = reachable with minor adjustment; > 6 Å = warhead too far, pose unproductive. Hard filter at `d_SG ≤ 4.5`.

### `geom_ok`

- **What:** Boolean — does the Boltz pose pass covalent-warhead geometry sanity checks?
- **How:** Stored in `top1000_manifest__zap70_cys346.json`; manifest-side rule combining `d_SG < 5 Å` AND warhead atom identified AND no constraint-violation flag. Merged in `backend.py:167`.
- **Intuition:** True = the pose can plausibly form the covalent bond. False = covalent constraint failed to converge or warhead atom couldn't be detected — discard the pose unless you have an independent reason to trust it.

### `n_h_bonds_cofold`

- **What:** Number of hinge / pocket hydrogen bonds in the cofold pose.
- **How:** Counted from the Boltz CIF during post-processing (distance + angle cutoff between donor-H–acceptor pairs), stored in the manifest, merged in `backend.py:168`.
- **Intuition:** Typical kinase hinge has 1-3 H-bonds (Met414 / Glu415 / Met416 backbone). 0 = ligand floating, no hinge engagement (suspicious). ≥ 2 = canonical hinge binder. NOT an affinity — just a contact count.

### `n_stabilizing_contacts`

- **What:** Count of non-covalent stabilising contacts (H-bonds + salt bridges + π-π) in the cofold pose.
- **How:** Same post-processing pipeline as `n_h_bonds`; aggregate count across contact types. Merged in `backend.py:168`.
- **Intuition:** Pocket-engagement count, not affinity. Typical range 3-12. Use to spot ligands that bind but don't engage the pocket richly (low contacts + reasonable iptm = surface association).

### `pocket_occupancy_pct`

- **What:** Percent of the ZAP70 ATP pocket volume occupied by the ligand.
- **How:** Computed by Voronoi/grid intersection of ligand atoms with the pocket residue mask; stored in the manifest; merged in `backend.py:169`.
- **Intuition:** Range 0-100%. ~60-85% typical for kinase ATP-site fillers. < 40% = small fragment-like; > 90% = potentially overpacked. Use with `d_SG` to distinguish "deep pocket binder with warhead reaching Cys346" from "edge binder".

## COFOLD CONFIDENCE

### `mPAE`

- **What:** Minimum PAE (predicted aligned error) between any ligand atom and any protein residue — best inter-chain confidence.
- **How:** `anchordiff/build_cys346_manifest_json.py:75-99`: parses `pae_<name>_model_0.npz`, takes `cross = pae[:n_protein, n_protein:]`, returns `np.min(cross)`. Merged in `backend.py:116`.
- **Intuition:** Lower = more confident. < 3 Å = high confidence inter-chain alignment; > 8 Å = ligand position is uncertain. Among Boltz's confidence metrics this is the *most discriminating* for ligand pose quality. Used in the leaderboard composite.

### `iptm`

- **What:** Interface predicted TM-score — Boltz's confidence in the interface only.
- **How:** Direct Boltz-2 output field `boltz_iptm`. Pulled from manifest in `backend.py:117`.
- **Intuition:** Range 0-1. > 0.85 = high confidence pose; < 0.70 = treat as suspect. Our 997-cofold cohort spans 0.5-0.98; top-20 sits 0.85-0.95.

### `ligand_iptm`

- **What:** Ligand-specific interface ipTM — confidence restricted to the ligand-pocket interface tokens.
- **How:** Boltz-2 output field `boltz_ligand_iptm`. Merged in `backend.py:118`.
- **Intuition:** More discriminating than whole-complex `iptm` for ligand-pocket fit. Preferred when ranking ligand poses. Same 0-1 scale. > 0.80 = strong ligand-interface confidence.

### `boltz_plddt`

- **What:** Complex pLDDT — per-residue confidence averaged over the complex.
- **How:** Boltz-2 output `boltz_complex_plddt`, merged in `backend.py:119`. Average of per-residue pLDDT confidences from the structure module.
- **Intuition:** Range 0-100. > 80 = high-confidence structure; < 70 = structurally uncertain. Primarily reflects protein-side confidence; less useful for ligand-pose ranking than `ligand_iptm`.

### `boltz_pde`

- **What:** Predicted distance error — average uncertainty in inter-atomic distances.
- **How:** Boltz-2 output `boltz_complex_pde`, merged in `backend.py:120`.
- **Intuition:** Lower = better. < 2 Å = tight predicted geometry. Complements PAE — PAE is alignment error, PDE is distance error.

### `boltz_confidence`

- **What:** Boltz-2 overall confidence score — weighted composite of iptm, ipLDDT, etc.
- **How:** Boltz-2 output `boltz_confidence_score`, merged in `backend.py:121`. The native Boltz ranking signal.
- **Intuition:** Range 0-1. > 0.85 = top-tier confidence. Useful for triaging the 997 cofolds; less granular than `ligand_iptm` for ligand specifics.

### `combined_score`

- **What:** Percentile-blended ranking score combining FiLMDelta pIC50 and Boltz ligand-iptm.
- **How:** `build_cys346_manifest_json.py:108-109`: `rank_score.rank(pct=True) * 0.6 + boltz_ligand_iptm.rank(pct=True) * 0.4`. Stored in manifest; merged in `backend.py:122`.
- **Intuition:** Range 0-1 (percentile space). The Top-20 leaderboard ranks on this. Rewards molecules that are both potent AND pose-confident; defends against pIC50 hallucinations on poses that don't fit the pocket.

## POCKET INTERACTION ENERGY

### `vina_kcalmol`

- **What:** AutoDock Vina estimated free energy of binding (kcal/mol) — total `--score_only` rescore on the Boltz pose.
- **How:** `experiments/vina_rescore_cofolds.py:265-301`: parses `Estimated Free Energy of Binding` from `vina --score_only` on the split Boltz cofold pose. Box centred on Cys346 Sγ, ≥ 22 Å, padded to cover ligand. Trott & Olson 2010 knowledge-based scoring function.
- **Intuition:** More negative = better. Kinase covalents typically score −7 to −10. < −2 = plausible binder; > 0 = significant clash. Orthogonal physics to MM-GBSA — catches entropy neglect and clash mis-scoring.

### `vina_inter_kcalmol`

- **What:** Final intermolecular energy (ligand-receptor only).
- **How:** `vina_rescore_cofolds.py:248`: parses `(1) Final Intermolecular Energy` line.
- **Intuition:** The "true" ligand-protein interaction component (no torsion / unbound terms). More negative = stronger receptor contacts.

### `vina_intra_kcalmol`

- **What:** Final total internal energy (ligand intramolecular).
- **How:** `vina_rescore_cofolds.py:251`: parses `(2) Final Total Internal Energy` line.
- **Intuition:** Ligand-only term. Large positive = strained ligand pose (the Boltz pose may have twisted bonds). Use as a cross-check against `rdkit_strain_kcal_mol`.

### `vdw_interaction_kcal_mol`

- **What:** UFF Lennard-Jones interaction energy between ligand and pocket residues — orthogonal vdW signal.
- **How:** `src/utils/rdkit_strain.py` `score_cofold(..., compute_interaction=True)` invoked by `experiments/score_rdkit_strain_batch.py:55`: UFF LJ over heavy atom pairs within 8 Å, excluding pairs closer than 2.5 Å (to exclude the warhead-Cys covalent bond partner).
- **Intuition:** More negative = better dispersion fit. Complements Vina's knowledge-based score with a force-field LJ term. Typical -10 to -40 kcal/mol; > -5 = poor vdW fit.

## COMPOUND STRAIN

### `rdkit_strain_kcal_mol`

- **What:** Pose-aware ligand internal strain (kcal/mol) — bound MMFF SP minus best-of-5 free conformer MMFF SP.
- **How:** `src/utils/rdkit_strain.py` `score_cofold(...)`, called by `score_rdkit_strain_batch.py --mode cofold`. Hydrogens-only relaxation on the Boltz pose (heavy atoms fixed), MMFF94s SP on the H-relaxed pose, minus min(5 ETKDG free conformer MMFF energies). Output column renamed in `backend.py:312`.
- **Intuition:** > 0 by construction (bound ≥ free). 0-3 = relaxed pose; 3-7 = mild strain; > 7 kcal/mol = the Boltz pose is sacrificing internal energy for pocket contacts — sanity-check the pose. Cofold cohort only.

### `rdkit_strain_posefree_kcal_mol`

- **What:** Pose-free / constitutional strain proxy — ETKDG single-conformer bound proxy MMFF SP minus free reference. Scaffold-independent.
- **How:** `score_rdkit_strain_batch.py --mode posefree` runs `score_posefree(smi, num_conf_free=2, free_max_its=100)` on every dashboard candidate: 1 unrelaxed ETKDGv3 conformer as bound proxy, best of 2 MMFF-relaxed conformers as free reference. Tuned for 520K-scale sweep — Spearman > 0.95 vs 5/300 settings on smoke test.
- **Intuition:** Available for every candidate (not just cofolded). Same direction as `rdkit_strain_kcal_mol` but a constitutional/intrinsic strain proxy without a pose. Use to triage candidates *before* expensive cofolding.

## WARHEAD REACTIVITY — xTB GFN2

### `LUMO_eV`

- **What:** Frontier unoccupied orbital energy (eV) at xTB GFN2 level — electrophilicity proxy.
- **How:** `experiments/xtb_warhead_electrophilicity.py:273` parses HOMO/LUMO from xTB stdout after `xtb input.xyz --gfn 2 --vfukui --json` on the ETKDG+MMFF free-state geometry.
- **Intuition:** Lower LUMO = more electrophilic Cβ = faster Michael addition. xTB GFN2 LUMOs are systematically ~4-5 eV lower than DFT/B3LYP (use for ranking only, not absolute kinetics). Acrylamide typical range −3 to −1 eV at xTB.

### `HOMO_eV`

- **What:** Frontier occupied orbital energy (eV) at xTB GFN2 level.
- **How:** Same parser as LUMO — `xtb_warhead_electrophilicity.py:273`.
- **Intuition:** Higher HOMO = more reducing. For a covalent acrylamide warhead, HOMO is less mechanism-relevant than LUMO; mostly used as part of `gap_eV` and `omega_eV`.

### `gap_eV`

- **What:** HOMO-LUMO gap (eV).
- **How:** `xtb_warhead_electrophilicity.py:279`: `LUMO - HOMO`.
- **Intuition:** Larger gap = harder/less reactive overall. Smaller gap = soft electrophile (Michael acceptor-ready). Typical acrylamide gap ~4-6 eV at xTB.

### `omega_eV`

- **What:** Parr global electrophilicity index ω (eV) — single scalar electrophilicity measure.
- **How:** `xtb_warhead_electrophilicity.py:282`: `((HOMO + LUMO)² / (2 × gap))`. Parr, Szentpály, Liu 1999.
- **Intuition:** Higher = more electrophilic. Caution: depends on both HOMO and LUMO so a large gap can inflate ω. Use as one of several electrophilicity reads, not alone.

### `q_Cb`

- **What:** Mulliken partial charge on the Cβ Michael-acceptor atom (xTB scale).
- **How:** `xtb_warhead_electrophilicity.py:296-299`: reads xTB's `charges` file (one float per atom in input order), indexes by `cb_idx` from the SMARTS match `[CH2]=[CH]-[C](=O)-[N]` (idx 0 = Cβ).
- **Intuition:** xTB scale; less-negative (closer to zero) = more electrophilic Cβ. Donor substitution on the amide N pushes electrons onto Cβ, makes q_Cβ more negative, SLOWS Michael addition. Range typically -0.30 to -0.10 in our library.

### `fukui_plus_Cb`

- **What:** Electrophilic Fukui function f⁺ on Cβ — local susceptibility to nucleophilic attack.
- **How:** `xtb_warhead_electrophilicity.py:301-304`: parses the `--vfukui` table from xTB stdout, indexes by `cb_idx`. f⁺ = ρ(N+1) − ρ(N).
- **Intuition:** Higher f⁺ at Cβ = nucleophile preferentially attacks here. Local complement to the global ω. Typical f⁺ at Cβ in acrylamide ~0.02-0.08.

### `pred_log_k2_GSH`

- **What:** Heuristic predicted log10 of the 2nd-order rate constant (M⁻¹s⁻¹) for glutathione addition to the warhead.
- **How:** `xtb_warhead_electrophilicity.py:195-202`: `-2.5 × (LUMO_eV + 7.0) + 6.0 × q_Cb − 1.0`. NOT a fitted regression — coefficients chosen to span the literature 4-log range (Flanagan JMC 2014; Awoonor-Williams & Rowley JCIM 2018). Use for ranking only.
- **Intuition:** Range ~-3 to +1. Higher = more reactive electrophile. Real measured k₂ for ibrutinib vs GSH ~0.1 M⁻¹s⁻¹ (log = -1). Avoid > 0 (too reactive — promiscuous covalent off-targets); avoid < -3 (too sluggish for productive on-target labeling).

## NUCLEOPHILE ACTIVATION

### `pKa_Cys346`

- **What:** Predicted Cys346 thiol pKa in the cofold pocket — nucleophile activation.
- **How:** `experiments/propka_cys346_pka.py:67-121`: runs `propka3 <pose.pdb>`, parses the SUMMARY block for `CYS 346 <chain> <pKa>`, prefers chain A. Olsson 2011 / Søndergaard 2011 framework.
- **Intuition:** Lower pKa = more thiolate at physiological pH = activated nucleophile. Free cysteine pKa ≈ 8.3. Pocket-activated Cys346 in known covalent kinases drops to 5-7. Combined with `pred_log_k2_GSH`, completes the rate equation: more activated nucleophile + more electrophilic warhead = faster on-target labeling.
