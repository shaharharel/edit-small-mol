## Key insights

1. **P5-1-v2 wins**: pairs are within-PDB (SAME pocket, SAME ligand-family) with fine-tune from Exp-N base. Model learns "given this ligand, this pocket, produce THIS structural variant" — reinforces exactly what base learned, but with real pairs instead of atom-permuted autoencoding.

2. **Warhead-swap (P5-4) HURTS warhead retention**: teaching model to swap warheads → model generates diverse (wrong) warheads. This was expert-predicted, now confirmed.

3. **CROSSPDB does OK**: has cross-PDB signal + preserves 64% warhead. Best geometry (3.10° planar, 13.43° BD). Could be useful for cross-pocket claims.

4. **Fine-tune from base is CRITICAL**: all v2 versions (with base_ckpt=Exp-N winner) massively outperform v1 versions (from mol2mol prior). Difference: −55pp to +9pp on P5-1 alone.

5. **HYBRID underperforms components**: combining warhead-swap + geometry pairs is not additive. Both signals compete.

## Winner path forward
- **Primary**: P5-1-v2 for lead-op quality retention
- **Best geometry**: P5-CROSSPDB-v2 for cross-pocket / novel-pocket claims
- **Baseline stays**: denoise for standalone use
